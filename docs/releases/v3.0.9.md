# UGreen Control v3.0.9

DXP8800 Pro 现在可以独立调节 CPU 风扇、联动调节两路系统风扇并分别查看三路转速。来电恢复支持开机、关机和恢复断电前状态。自动温控采用 DXP8800 专属软件曲线，参数取自 1.17 原厂配置。写入需要精确型号匹配和确认。模拟硬件测试已通过，实机散热和断电恢复仍待验证。[固件证据](https://github.com/BearHero520/UGREEN-NAS-Hardware/blob/abfe71a07e5b10e79d78bc637dfec14eba514de0/docs/DXP8800_PRO_AUDIT.zh-CN.md)

LED 操作现在串行执行。部分写入失败时清除对应缓存，硬件报错后暂停重试十秒，避免并发请求反复写入。此次也包含 DXP2800 EM26 的机型适配，并修正 DXP8800 系列的型号显示。

适用平台为 x86 飞牛 fnOS 0.9.27 及以上。下载版本化 FPK，可用同名 SHA-256 文件校验。
